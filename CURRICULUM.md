# Curriculum map and originality

## Originality statement
Everything in CS Penguins is original work made for this project: the lesson text (English and Greek), the
examples, the quiz questions, the penguin pictures and animations, the sounds and the code. No textbook text,
exercise, picture or code from another author or publisher was copied. The Greek Gymnasium and Lyceum
curricula were used only as a list of *topics* to decide what to teach, and topics and ideas (binary numbers,
sorting, spreadsheets ...) are not owned by anyone. The made-up names, passwords, web addresses and messages in
the lessons use `.example` addresses and invented brands so they cannot point to a real person or company.
Third-party libraries: none in the site (plain JavaScript). The teacher PDFs are made with the open-source
ReportLab library (not shipped on the site). If you add material later, keep it original or check its licence
and write the credit in this file.

## Which lessons cover which topics
This map is based on my general knowledge of the Greek school informatics programmes, NOT on the official
text. Please check it against the current official programmes (Ινστιτούτο Εκπαιδευτικής Πολιτικής) before you
advertise it as "covering the curriculum".

|---|---|
| How a computer works (input, CPU, memory, storage, output) | Inside the Computer (`hw`) |
| Binary numbers, data representation | Binary Numbers (`bits`), Letters and Pictures as Numbers (`rep`), Data Types (`types`) |
| Files, folders, operating system basics | Files and Folders (`os`) |
| Spreadsheets: cells, formulas, SUM/MAX | Spreadsheets (`sheet`), Data and Charts (`data`) |
| Databases: tables, filter, sort | Databases (`db`) |
| Internet and networks | How the Internet Sends a Message (`net`) |
| Safe and responsible use: passwords, phishing, privacy, copyright, sources | Passwords and Phishing (`sec`), Digital Citizenship (`cit`), Secret Messages (`cipher`) |

| Variables, conditions, loops | Variables (`vars`), If and Else (`cond`), Loops (`loop`) |
| Arrays, functions, recursion | Arrays (`arr`), Functions (`func`), Recursion (`rec`) |

## What is NOT covered (be honest with customers)
- Word processing, presentations and multimedia software skills.
- Programming in a real language (Scratch, Python, the Lyceum "ΓΛΩΣΣΑ" pseudo-language). Lessons use short
  plain pseudocode and pictures, not a typed-code editor.
- Web page design (HTML/CSS), robotics hardware, object-oriented programming, formal complexity (big-O)
  proofs, and exam-style written problems.
So CS Penguins supports the *ideas* of the curriculum for ages 7-15, it does not replace the school textbook.

## How the lessons work (be honest)
Each of the 39 lessons is an animated step-by-step player plus a "what happens next?" practice quiz.
The lessons are shelved in six topics, like school books, each with a penguin-themed name:
Computer Systems (PenguMachines), Programming (Pengramming), Algorithms (Pengurithms), Data Structures and Graphs
(Pengustructures), Data and Information (PenguData) and Internet and Digital Safety (PenguNet).

Games (levels with stars): Breadth-First Search, Depth-First Search, Quick Sort, "Program the Penguin" (4 levels),
"Light the Lamp" (5), and 41 small games: binary cards (5), higher-or-lower (3), code breaker (4), rebuild the
packets (3), put the steps in order (3), sort the gadgets and data types into bins (4), folder quest (3), penguin
detective / database filters (5), phish spotter (4), formula factory (4) and bubble dock (3). Chapters not named
here (for example variables, recursion, AI basics) are still lesson plus quiz, not games.
