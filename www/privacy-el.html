Ποιοι είμαστε

Το CS Penguins είναι ένα δωρεάν εκπαιδευτικό project, φτιαγμένο από έναν ανεξάρτητο προγραμματιστή στην Ελλάδα. Για επικοινωνία, άνοιξε ένα issue στη σελίδα του project στο GitHub.

Εν συντομία

  • Το CS Penguins δεν έχει λογαριασμούς, σύνδεση, πληρωμές, διαφημίσεις ή εργαλεία παρακολούθησης.
  • Δεν ζητάμε, δεν συλλέγουμε και δεν αποθηκεύουμε προσωπικά στοιχεία.
  • Η πρόοδός σου στο παιχνίδι (αστέρια, βαθμολογίες κουίζ, σειρά ημερών στο καθημερινό παζλ, το όνομα στο πιστοποιητικό, η γλώσσα και ο ήχος) αποθηκεύεται μόνο στο δικό σου πρόγραμμα περιήγησης, στη δική σου συσκευή. Αν καθαρίσεις τα δεδομένα του προγράμματος, σβήνεται.

Φιλοξενία

Ο ιστότοπος είναι ένα σύνολο στατικών αρχείων. Η εταιρεία που φιλοξενεί τα αρχεία μπορεί να κρατά για μικρό διάστημα τεχνικά αρχεία καταγραφής, όπως τη διεύθυνση IP, για να παραμένει η υπηρεσία ασφαλής και σε λειτουργία. Δεν τα χρησιμοποιούμε για να αναγνωρίσουμε κανέναν.

Παιδιά

Τα μαθήματα φτιάχτηκαν για ηλικίες 7–15. Επειδή δεν συλλέγουμε προσωπικά στοιχεία, τα παιδιά δεν χρειάζεται να μας δώσουν κανένα.

Τα δικαιώματά σου

Μπορείς να ζητήσεις πρόσβαση, διόρθωση, φορητότητα ή διαγραφή των δεδομένων σου, να αντιταχθείς στη χρήση τους ή να υποβάλεις καταγγελία στην Αρχή Προστασίας Δεδομένων Προσωπικού Χαρακτήρα (www.dpa.gr). Επικοινώνησε μαζί μας μέσω της σελίδας του project στο GitHub (δες παραπάνω).

Αλλαγές

Αν αλλάξουμε αυτή την πολιτική, θα ενημερώσουμε την ημερομηνία στην κορυφή.
