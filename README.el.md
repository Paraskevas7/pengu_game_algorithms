# CS Penguins

**[▶ Παίξε το εδώ](https://paraskevas7.github.io/pengu_game_algorithms/)** (δουλεύει σε κινητό, tablet και υπολογιστή, χωρίς εγκατάσταση) · [English](README.md)

[![CI](https://github.com/Paraskevas7/pengu_game_algorithms/actions/workflows/ci.yml/badge.svg)](https://github.com/Paraskevas7/pengu_game_algorithms/actions/workflows/ci.yml)

Ένας δωρεάν ιστότοπος (και αργότερα εφαρμογή) που διδάσκει **πληροφορική** (συστήματα, προγραμματισμό, αλγορίθμους, δομές δεδομένων, δεδομένα, ασφάλεια στο διαδίκτυο) σε παιδιά 7 έως 15 ετών, με πιγκουίνους, στα Αγγλικά και στα Ελληνικά. Τα 39 μαθήματα είναι χωρισμένα σε έξι θέματα (PenguMachines, Pengramming, Pengurithms, Pengustructures, PenguData, PenguNet) και πολλά έχουν μικρά παιχνίδια (συνολικά 59 επίπεδα παιχνιδιού, με 3 αστέρια το καθένα).
Απλό HTML/CSS/JS, χωρίς λογαριασμούς, χωρίς σύνδεση και χωρίς παρακολούθηση. Πακεταρισμένο για iOS και Android με το [Capacitor](https://capacitorjs.com).

## Παίξε το από το GitHub (κινητό ή υπολογιστής)
Το παιχνίδι σερβίρεται από το **GitHub Pages**, από τον φάκελο `docs/`. Για να το ενεργοποιήσεις μία φορά: στο repository πήγαινε **Settings > Pages > Build and deployment > Source: Deploy from a branch > Branch: `main` και φάκελος `/docs` > Save**. Σε ένα με δύο λεπτά το παιχνίδι είναι ζωντανό στον σύνδεσμο από πάνω και μπορεί να το ανοίξει οποιοσδήποτε σε πρόγραμμα περιήγησης.

## Τι περιέχει
**Μάθε:** μια σύντομη εξήγηση, ένα κινούμενο παράδειγμα με πιγκουίνους που μπορείς να παίξεις, να σταματήσεις, να προχωρήσεις βήμα βήμα και να γυρίσεις πίσω, ο ψευδοκώδικας με επισήμανση της τρέχουσας γραμμής και ένα κουτί «καλό να ξέρεις». **Εξάσκηση:** επίπεδα παιχνιδιού (λειτουργία Παρακολούθησης και Παιχνιδιού, 3 / 2 / 1 αστέρια) και κουίζ για τα υπόλοιπα μαθήματα. Υπάρχει επίσης καθημερινό παζλ και πιστοποιητικό. Η πρόοδος αποθηκεύεται μόνο στη συσκευή (localStorage).

## Πώς είναι φτιαγμένο
- **Χωρίς frameworks, χωρίς βιβλιοθήκες.** Απλό HTML, CSS και JavaScript (23 μικρές ενότητες στο `www/js`), οπότε όλο το παιχνίδι είναι ένα μικρό αρχείο που φορτώνει αμέσως και τρέχει παντού.
- **Οι αλγόριθμοι είναι ξεχωριστοί από τις εικόνες.** Τα `algos.js` και `graphs.js` υπολογίζουν BFS, DFS, Dijkstra, Prim, Kruskal, Bellman-Ford και τους αλγορίθμους ταξινόμησης ως λίστες βημάτων («ίχνη»). Το `frames.js` μετατρέπει κάθε ίχνος σε βήμα μαθήματος με απλά λόγια και το `draw.js` το ζωγραφίζει. Το ίδιο ίχνος τροφοδοτεί την κινούμενη εικόνα του μαθήματος, τη λειτουργία «Παρακολούθηση» και τη λειτουργία «Παιχνίδι».
- **Δύο γλώσσες από την ίδια βάση κώδικα.** Όλα τα κείμενα περνούν από το `I18n.t(key)`. Μια δοκιμή ελέγχει ότι τα αγγλικά και τα ελληνικά αρχεία έχουν ακριβώς τα ίδια κλειδιά και τα ίδια σημεία αντικατάστασης, και ότι τα ελληνικά είναι πραγματικά μεταφρασμένα.
- **Δοκιμασμένο.** 68 δοκιμές (`npm test`, τρέχουν αυτόματα από το GitHub σε κάθε push) ελέγχουν τους αλγορίθμους με γνωστές απαντήσεις, ότι τα επίπεδα παιχνιδιού λύνονται, ότι η βαθμολογία με αστέρια δουλεύει, ότι κάθε εικόνα ζωγραφίζεται σε κάθε βήμα κάθε μαθήματος και ότι οι μεταφράσεις ταιριάζουν.
- **Δουλεύει χωρίς σύνδεση και εγκαθίσταται σαν εφαρμογή.** Ένα service worker (που φτιάχνει το `tools/build.py`) αποθηκεύει το παιχνίδι και ένα web manifest σου επιτρέπει να το προσθέσεις στην αρχική οθόνη. Ο φάκελος `docs/` είναι ο έτοιμος ιστότοπος που σερβίρει το GitHub Pages.
- **Ιδιωτικό εξ ορισμού.** Χωρίς λογαριασμούς, χωρίς παρακολούθηση, τίποτα δεν φεύγει από τη συσκευή. Η πρόοδος μένει στο `localStorage`.

## Τρέξε το στον υπολογιστή σου
```bash
npm run serve        # μετά άνοιξε http://localhost:8080
npm test             # δοκιμές (δεν χρειάζεται εγκατάσταση)
python3 tools/build.py   # φτιάχνει το dist/index.html (ΕΝΑ αρχείο για οποιονδήποτε στατικό διακομιστή) και τον φάκελο docs/
```
Άνοιξέ το στο Chrome και χρησιμοποίησε την προβολή κινητού (F12 → γραμμή συσκευών) για να δεις τη διάταξη για κινητό.

## Βάλε το στο διαδίκτυο
**GitHub Pages:** δες το «Παίξε το από το GitHub» παραπάνω. Ο φάκελος `docs/` ξαναφτιάχνεται με `python3 tools/build.py`. Μπορείς επίσης να ανεβάσεις το `dist/index.html` σε οποιονδήποτε στατικό διακομιστή (Netlify Drop, Cloudflare Pages ή δικό σου server). Δεν χρειάζεται κώδικας server, λογαριασμοί, ούτε φορτώνει τίποτα από άλλους ιστότοπους.

## Βάλε το στα καταστήματα εφαρμογών
1. **Άλλαξε το app id** στο `capacitor.config.json` (`com.yourname.pengurithm`) σε δικό σου. Δεν αλλάζει μετά τη δημοσίευση.
2. Εγκατάστησε και πρόσθεσε τις πλατφόρμες: `npm install`, `npx cap add android`, `npx cap add ios` (μόνο σε macOS με Xcode), `npx @capacitor/assets generate`, `npx cap sync`.
3. Δοκίμασε σε συσκευή ή εξομοιωτή: `npx cap open android` ή `npx cap open ios`. Κάθε φορά που αλλάζεις κάτι στο `www/`, τρέξε ξανά `npx cap sync`.
4. **Google Play:** λογαριασμός προγραμματιστή (25$ μία φορά), υπογεγραμμένο `.aab` από το Android Studio (φύλαξε το keystore), φόρμα ασφάλειας δεδομένων (η εφαρμογή δεν συλλέγει δεδομένα) και σύνδεσμος πολιτικής απορρήτου. **Apple App Store:** Mac με Xcode και λογαριασμός Apple Developer (99$/χρόνο).

## Δομή του project
```
www/index.html        σελίδα εισόδου
www/style.css         εμφάνιση
www/js/               ο κώδικας (αλγόριθμοι, μαθήματα, παιχνίδια, μεταφράσεις)
tools/build.py        δημιουργεί dist/ και docs/
test/                 δοκιμές
assets/               εικονίδιο εφαρμογής
capacitor.config.json ρυθμίσεις για iOS και Android
```
Δες το `CURRICULUM.md` για τον χάρτη της ύλης και τη δήλωση πρωτοτυπίας, και το `README.md` για την αγγλική έκδοση με τη λίστα των μαθημάτων.
